# Guion para el manual de usuario en video

**Duración sugerida:** 7–10 minutos. Grabar la aplicación local con datos de demostración, ocultando `.env` y claves personales. No mostrar documentos empresariales reales.

## Antes de grabar

- Ejecutar el proyecto con una base de demostración, no con datos privados.
- Tener listas cuentas de prueba para admin, empresa aprobada y candidato.
- Preparar un PDF de prueba ficticio para el registro empresarial.
- Cerrar pestañas y notificaciones que no formen parte de la demostración.

## Recorrido

1. **(0:00–0:40) Portada:** explicar que rumbo conecta empresas con candidatos; mostrar el buscador y vacantes destacadas.
2. **(0:40–1:30) Crear candidato:** abrir acceso, registrar una cuenta y mencionar la validación de correo único.
3. **(1:30–2:40) Buscar y postularse:** filtrar vacantes, abrir detalle, completar perfil y aplicar; mostrar el panel y estado de la solicitud.
4. **(2:40–3:40) Solicitud de empresa:** mostrar el formulario, adjuntar el PDF ficticio y explicar que queda en revisión administrativa.
5. **(3:40–5:20) Administración:** entrar como admin, abrir Gestión de empresas, revisar Ver detalle y abrir el PDF; aprobar la empresa. Mostrar gestión de usuarios, vacantes y moderación.
6. **(5:20–6:45) Empresa:** entrar como la empresa aprobada, crear una oferta, ver postulantes y cambiar una solicitud a entrevista/aceptado.
7. **(6:45–7:30) Mantenimiento:** pausar/reactivar o eliminar una vacante y enseñar las métricas del dashboard empresarial.
8. **(7:30–8:00) Cierre:** resumir roles, seguridad de contraseñas, PostgreSQL y enlace al repositorio.

## Entrega del video

Exportar a MP4, reproducir el archivo completo para confirmar audio e imagen, y subirlo a la plataforma que indique el docente. Si se entrega enlace, comprobar permisos de visualización desde una ventana privada.
